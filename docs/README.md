WindyMail is a web-based personal contact manager built using the LAMP stack.

##

* Linux (Ubuntu)
* Apache
* MySQL
* PHP
* HTML
* CSS
* JavaScript

## Features

* User Registration
* User Login
* Add Contacts
* Search Contacts
* Edit Contacts
* Delete Contacts
* Secure Password Hashing
* Responsive User Interface

## App URL

https://windymail.top

## Project Structure

* LAMPAPI - Backend PHP APIs
* css - Styling files
* js - JavaScript functionality
* images - Project assets
* database - SQL schema
* docs - Documentation
