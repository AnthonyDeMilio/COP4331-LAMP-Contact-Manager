## Project Description

WindyMail is a personal contact manager built using a LAMP stack. Users can register, log in, and manage their own contacts through a secure web interface.

## Technologies Used

* Linux
* Apache
* MySQL
* PHP
* JavaScript
* AJAX
* JSON
* Digital Ocean

## Features

* User Registration
* User Login
* Add Contacts
* Search Contacts
* Update Contacts
* Delete Contacts

## API Endpoints

* Login.php
